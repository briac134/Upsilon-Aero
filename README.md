# Upsilon-Aero: Frutiger Aero theme for Upsilon

The theme is derived from both Upsilon's and Numworks' official icons

## Installation
This theme uses the Upsilon's third-party theme system.

Clone Upsilon then compile it with the theme repository and theme name:

```make THEME_REPO="https://github.com/briac134/Upsilon-Aero.git" THEME_NAME="frutiger_aero"```

## Recommandations
I personnally think the theme looks better with a background — you can install one from: https://upsilonnumworks.github.io/Upsilon-External/
